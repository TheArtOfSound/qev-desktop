Documentation · Free path

Browser envelope tool

Use the QEV browser vault: seal a message in-tab with no account. Offline after load; phrase never sent to our servers for the free vault path.

Fastest start. No account. No install. Best first evaluation of QEV.

What to do

  1. Open https://secure.imagineqira.com/vault.
  2. Type your message and a strong passphrase.
  3. Export the vault file.
  4. Send the file one way; share the phrase another way.
  5. Recipient opens the same vault page (or desktop/CLI) and unlocks.

Trust properties of this path

  • Plaintext is sealed in the browser for the free vault tool.
  • After load, the tool is designed so sealing does not require calling home with your secret.
  • This marketing site itself is integrity-signed — if HTML is swapped after signing, you should see a tamper warning.

When to leave the browser tool

  • Need desktop convenience → Download
  • Need automation → CLI on npm (@bryan237l/qev-cli)
  • Need workflow capture for a team → Gateway pilot
