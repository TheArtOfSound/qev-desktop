Trust

Trust-mark levels

Compatible, Verified Workflow, Protected Workflow, Independently Assessed — what each level means and what is issuable today.

Badges alone prove nothing. Only a linked signed certificate with live status is the trust object. See Trust program.
  1. QEV Compatible — format / interoperability tests. Issuable in pilot tooling for format checks.
  2. QEV Verified Workflow — configuration baseline for a named workflow. Not yet public-issuable at scale.
  3. QEV Protected Workflow — continuous controls. Not yet issuable.
  4. QEV Independently Assessed — external firm. Not yet issuable.

Today’s public product is a controlled-use preview. Only Compatible and internal Pilot Configuration Passed are realistic marks.
