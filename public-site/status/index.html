Why test counts differ

They are different codebases and suites, not “failed tests missing from the homepage.”

  • 258 — product preview / policy-demo path (as stated on the main site).
  • 362 — desktop binary pipeline claim on the downloads page.
  • CLI self-test — small focused suite for the npm package only.
  • qev-platform — separate Vitest monorepo for the commercial gateway.

Never mix these numbers into one “QEV has N tests” claim without naming the component.
